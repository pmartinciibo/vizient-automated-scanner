18) Algorithms:

	ToolScanningLogic(tool)
		Locate the ScanProgress entry in Settings for this tool (Name = tool name):
			set scanId = Scan.Id
			set startedAt = Now
			set endedAt = null
			set Status=InProgress
			set percentComplete=0
			set message='Scan starting...'
			Save the Setting
		Locate the Scan.ScanTool(Name = tool name)
			set Status=InProgress
		StartTheScan(tool)
		In 5% progress increments update the Setting percentComplete and message to reflect the progress
		If failure:
			set Setting.Status=Failure
			set Setting.message to the error message
			set endedAt=Now
			Save the Setting
		If success:
			set Setting.Status=Success
			set Setting.message = null
			set endedAt=Now
			Save the Setting

	GetApplication(name, isDisabled)
		Locate the internal Application[Name=name or using ToolMapping]
		If found:
			set Application.ScanStatus=Found
		If !found:
			Create the Application(Status=Enabled,ScanStatus=New)
		If isDisabled:
			set Application.Status=Disabled
		return Application

	GetApplicationRepository(Application, repoName, repoPath, source, isDisabled)
		Locate the internal Repository[Application=Application, Name=repoName or using ToolMappping]
		If found:
			set Repository.ScanStatus=Found
		If !found:
			Create the Repository(ApplicationId=Application.Id,Status=Enabled,ScanStatus=New,RepoPath=repoPath,Source=source,LastScannedAt=Now)
		If isDisabled:
			set Repository.Status=Disabled
		return Repository

	StartTheScan(tool=Rapid7)
		For each Rapid7.application:
			Application = GetApplication(Rapid7.application.name, Rapid7.application.status=disabled)
			For each Vulnerability:
				ToolFoundVulnerability(tool, Application, null, Vulnerability)

	StartTheScan(tool=CheckMarx)
		For each CheckMarx.application:
			Application = GetApplication(CheckMarx.application.name, CheckMarx.application.status=disabled)
			For each repository:
				Repository = GetApplicationRepository(Application, repository.name, repository.path, repository.source, repository.status=disabled)
				For each Vulnerability:
					ToolFoundVulnerability(tool, Application, Repository, Vulnerability)

	StartTheScan(tool=SemGrep, Snyk, TruffleHog, Sonar Standard and Sonar for .Net)
		For each Application:
			For each Repository:
				Scan the repo: 
					For each Vulnerability:
						ToolFoundVulnerability(tool, Application, Repository, Vulnerability)

	ToolFoundVulnerability(tool, Application, Repository, toolFinding)
		Locate the corresponding Finding where UniqueIdentifier=toolFinding.ID
		if found:
			set Finding.ScanStatus=Found
			If needed, update Finding.Status to the appropriate value to match the scanning tool, and create FindingHistory
		if !found:
			Create the Finding for the Application (using ToolMapping to locate our Application) with Status=New, ScanStatus=New
			Create the FindingHistory
			Create the ScanToolFinding

	Scanning Logic:
		1. For each Application:
			set Application.ScanStatus = NotFound
			For each Repository in Application.Repositories where Status=Enabled:
				set Repository.ScanStatus = NotFound
			For each Finding where Status in (New, UnReviewed):
				set Finding.ScanStatus=NotFound
			Create a scan with Status=Pending and StartedAt=Now
			For each Tool:
				Create a ScanTool for the Scan with Status=Pending
		2. Run in parallel:
			a. ToolScanningLogic(Rapid7)
			b. ToolScanningLogic(CheckMarx)
			c. SyncRepos()
				When finished run in parallel:
					a. ToolScanningLogic(SemGrep)
					b. ToolScanningLogic(Snyk)
					c. ToolScanningLogic(TruffleHog)
					d. ToolScanningLogic(Sonar Standard)
					e. ToolScanningLogic(Sonar .Net)
		3. When all tools have completed:
			If one failed:
				set Scan.Status=Failed
			If all successful:
				For each Application
					switch(ScanStatus)
						NotFound
							set Application.Status=Missing
						New
						Found
							For each Repository
								switch(ScanStatus)
									NotFound
										set Repository.Status=Missing
									New
									Found
										For each Finding:
											switch(ScanStatus)
												NotFound
													set Status=Remediated
													Create new FindingHistory
												Found
												New
				set Scan.Status=Success
			set Scan.CompletedAt=Now
		4. Deduplify across tools
			For each Finding in the current Scan:
				Look for all findings with the same app/repo/file/line number
					If it appears to be a duplicate:
						Delete one of the findings, and repoint the entry for the deleted finding in ScanFindings to the other finding
		5. //Create scan results
			For each Application
				For each Repository
					CreateScanResults(Application, Repository, New, Critical, Findings[ApplicationId=Application.Id,RepositoryId=Repository.Id,])

	* New findings for this scan
		All ScanToolFindings for ScanTool represent new findings
	** Remediated findings since last scan
		All FindingHistory for this Scan where NewStatus=Remediated represent remediated findings
